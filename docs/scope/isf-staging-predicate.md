# Scope — ISF staging predicate

## Decisions

- ISF direction and queue register remain separate from stageability. A harm-owned weaken may say that corrections look stronger than needed and remain in the asserting register while naming no programmable number. This preserves ADR 25 and ADR 42 instead of collapsing direction, ranking, and staging into one fact. → ADR
- This is a shipped Diagnose revision. Execution uses `uv run harmonic serve --no-fetch --db mockups/revise-e2e.synthetic/harmonic.sqlite`, the manufactured database generated by `scripts/gen_revise_e2e_db.py`, the frozen behavior ledger `mockups/finding-evidence-routing.behavior.md`, and the app-only replay `frontend/diagnose-workstation-behavior.replay.mjs`. The locked mock is archived and no mock-side artifact is created. inline
- The ISF analyzer keeps its own evidence regime and half-gap cap. It does not route through basal `cap()`, acquire basal support floors, enter the consolidated profile, or change when it weakens, strengthens, or confirms. This is the real boundary of the shared staging invariant. → ADR
- When no programmed ISF exists, the analyzer emits no `recommended` value. Diagnose still shows the Estimate, interval, support, and analyzer annotation; the shared Recommended row remains in its reserved position with no numeric value, and there is no stage control. The uncapped per-night median remains in backend evidence rather than being presented as advice. This keeps the shared held-panel geometry and prevents a directionless measurement from looking programmable. → ADR
- An ISF result may create a Plan change only when a current programmed value exists, the analyzer names a direction, and the recommended value differs from current. The backend exposes this as the row's one explicit staging verdict; consumers do not reconstruct the rule. This rejects directionless measurements and half-gap moves that round back to the programmed value. → ADR
- An older or malformed payload with no explicit ISF staging verdict fails closed. Diagnose and Plan keep its evidence visible but offer no stage control and create no Plan item. This preserves useful evidence without silently treating a missing safety decision as permission. → ADR
- The findings projection carries stageability separately from its direction-derived queue register. A false or missing verdict may still produce an asserting ISF queue row, but that row prints no action number and exposes no stage affordance. A rounded strengthen no-op keeps the strengthen direction and analyzer annotation, uses the reserved empty Recommended row, and says the conservative step rounds to the ISF already programmed; it never falls through to weaken/recent-low language. → ADR

### Risk contract

- **Must prevent:** A row without an explicit backend staging verdict must never be presented as an actionable recommendation or create a Plan change. A stale cached analysis row with no programmed factor must never expose an uncapped measured number as Recommended or fan it across newly visible pump segments. A rounded no-op must never be presented as a programmable change. Silent incorrect success is prohibited.
- **Must recover:** No automatic recovery is required; this change is a read-and-stage gate and writes no authoritative pump data.
- **Accepted failure:** An older or malformed payload without an explicit staging verdict remains readable but non-stageable; manual recovery is to refresh or regenerate the analysis payload.
- **Unsupported:** Cross-process result-cache invalidation; changing ISF direction, recurrence, caps, evidence, priority, queue register, or consolidated-profile membership; inventing a daytime ISF schedule.
- **Evidence owed:** Analyzer output for direction-only weaken, strengthen, confirm/hold, no-programmed, and rounded no-op shapes; `recommended = null` with preserved measured estimate and evidence for no-programmed output; projection, queue, Plan, and detail reads of the backend verdict; preserved interval, support, annotation, queue register, direction copy, and shared panel geometry; generated pump-profile proof of true-verdict fan-out; generator/mirror drift checks; frozen behavior replay; distinct base/revision renders at both locked viewports and themes.

Why: Harmonic gives advisory insulin-dosing guidance, and the reproduced stale-cache shape currently stages a directionless raw measurement.
Disposition: → ADR
