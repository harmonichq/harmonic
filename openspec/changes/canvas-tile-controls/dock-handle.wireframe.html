The dock handle

One concept, drawn out. The chrome grows with the space the state can afford. Hidden pays a single quiet handle; docked pays that same handle plus two controls; mounted gets a real header row, because mounted is the only state with room for one. Nothing overlaps a chart in any state.

Mounted takes the whole left area and the glucose strip goes entirely, so the header row the strip's caption occupied becomes the mounted thing's own header — a title, a shrink and an ×. That row is shared: a full-screened chart gets exactly the same treatment with its own name in it, which is why the mounted dock and a mounted chart do not need two different answers.

The handle rides the dock's top edge. With the dock hidden, the dock's top edge is the canvas floor, so that is where the handle sits — it does not hop between unrelated edges, it is attached to one object and moves because that object moved. In hidden it is always drawn, quietly: with the dock away there is nothing else on screen saying the charts exist, and a hover-revealed control does not exist at all on a touch device. Docked, it may ghost — the dock underneath it is its own proof.

Tall viewport — hidden is not reachable, so the handle only mounts

The minis are not hideable while there is room, so docked's handle offers mount alone. Hide is absent rather than disabled: a control that never works is worse than one that is not drawn.

Press the handle's mount. Then shrink, and ×, from the header.

Short viewport — the dock hides itself, and hide comes back

Below the floor the dock hides on its own and the handle sits on the canvas floor at full opacity. Raised, it floats over the spotlight and the handle rides its top edge, now carrying both mount and hide.

Press the handle; mount from there; × back out.
