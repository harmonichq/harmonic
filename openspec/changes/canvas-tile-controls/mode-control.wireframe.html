The mode control — what it is, and which half it lives in

Ruled in round one and fixed in every specimen: the band runs the full window width as one shelf, and the canvas instruments are framed to the canvas column — WINDOW hard left, the pin schematic hard right against the canvas/inspector seam. Only the mode control varies below.

Grounded first, because it decides this round: the inspector's crumb root already prints the mode — crumbLabel returns "Findings" for the root frame and "Explore" in explore mode. The app names the mode twice today, one row apart. Both words are settled terms in CONTEXT.md, so neither can be renamed away.

Grounded second: the mode is mostly an inspector switch. advisoryPresentation turns off the rank filament, rank chips, tallies, staging and recommendation copy — all inspector content — and inspectorStackForMode rewrites the inspector's own stack. It also reorders tile seating, so it is not purely one pane's.

M-A

The crumb root is the control

No mode control in the rail at all. The word the inspector already prints as its root becomes the control in place: Findings | Explore where "Findings" is today, the live one in ink with the mode rung under it. The duplicate word disappears, and the control sits on the pane it mostly governs. The rail's inspector half stays bare material. Cost: the crumb root is also the pop-to-root target, so at depth one word has two jobs — see the "drilled" specimen, where the control has to collapse back to a plain ancestor link and the mode becomes unreachable without popping first.

M-B

A throw switch in the rail's inspector half

The mode becomes a lever — a recessed track with a raised thumb that carries the live word and sits physically at one end of the throw — seated in the rail's inspector half, hard left so it stacks directly above the crumb root it renames - measured at 1280, the lever's left edge is x=864 and the crumb root's is x=862, so the two line up within 2px. The empty shelf round one objected to is now the mode's home, and the control looks like a machine's mode selector rather than two text tabs. Cost: the mode word is still printed twice, 42px apart — lever and crumb root. Removing it from the crumb is a shipped-behavior removal and needs your sanction; without that, the duplicate is the price.

M-C

The throw straddles the seam

Same lever, sited centred on the canvas/inspector seam so it belongs to neither column — which is what it actually is: it reorders canvas tile seating and rewrites inspector content in one press. The seam becomes the rail's one hinge. Cost: it aligns to nothing — not the canvas grid, not the inspector's left edge — and it moves horizontally whenever the inspector width changes, so the one control that governs both panes is the one control with no fixed address. And it does not merely crowd the pin schematic that round one just pushed against that seam - measured at 1280 it overlaps it by 77px, the lever's left half landing on top of "0/4 PINNED"; the specimen shows the collision rather than hiding it.
