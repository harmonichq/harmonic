# --- The app's source root (#389, #495). It is a SHIPPING tree: the packaged
# image builds the one shell from this tree alone, so this root and its build
# configuration above must both ship or the app cannot be built at all. Its
# built output is generated during packaging and is untracked, so it is never a
# candidate input here.
#
# No binary class is added here. HV2-08 keeps Inter as the single UI family and
# HV2-01 forbids a CDN, so the font travels in the tree — as a CSS resource
# carrying its bytes as data URLs (frontend/fonts/inter.css), cleared by the
# .css extension below. That keeps every shipping file text, which is what the
# contamination scan reads; a WOFF2 beside it would fail that scan closed, and
# the scan is right to do so.
# The font licence must travel with the font. Exact-path, because .txt is not in
# the extension set above and should not be widened for one file.
frontend/fonts/OFL.txt
